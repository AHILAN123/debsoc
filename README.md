# DEBSOC IIEST Website

Official website of DEBSOC IIEST.  
Live Website: https://debsociiests.in

## About DEBSOC

DEBSOC IIEST is a student-driven society focused on debates, discussions, public speaking, diplomacy, and intellectual engagement. The society aims to create an environment where students can improve communication skills, critical thinking, leadership, and awareness of global and social issues through debates, MUNs, discussions, and related activities.

This website serves as the official online platform for DEBSOC IIEST, providing information about the society, events, activities, team members, and future initiatives.

---

## Website Architecture

The website follows a simple static frontend architecture.

### Flow

- User visits the website.
- The homepage acts as the entry point.
- Different pages are accessible through navigation links.
- Each page contains information related to DEBSOC activities, events, announcements, and society details.
- Future backend integration will support dynamic features and data handling.
